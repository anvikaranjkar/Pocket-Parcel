# Pocket Parcel

Pocket Parcel is a free, personal digital care-package maker. Every goodie can be customised, all parcel data is encoded into the shareable URL, and no account, payment, database or environment variable is required.

## Deploy on Vercel

1. Upload the contents of this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the detected framework as **Next.js** and select **Deploy**.

The included vercel.json runs the standard Next.js production build. No extra configuration is needed.

## Local development

For a Vercel-style local preview, run npm install followed by npm run vercel-dev.
